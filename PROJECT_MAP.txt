   ├─ category_ids (JSON)

   ├─ id (PK)
   ├─ provider_id (FK)
   ├─ title, description, price
   └─ estimated_time

   ├─ id (PK)
   ├─ user_id, provider_id (FK)
   ├─ rating (1-5), comment
   └─ created_at

📊 electronics_categories
   ├─ id (PK)
   └─ name, icon (8 categories pre-loaded)

📊 uploaded_files
   ├─ id (PK)
   ├─ user_id (FK)
   ├─ filename, file_path, upload_type
   └─ uploaded_at

📊 sessions
   ├─ session_id (PK)
